## PWSCUP 2025 Scripts — Usage Guide

This guide summarizes common workflows, commands, and tips for running the anonymization, evaluation, and attack scripts. Examples assume Windows paths; adjust as needed.

## Folders
- Input: place `B22_*.csv` files under `in\`
- Output: generated files go to `out\` (e.g., `C22_*.csv`, `C22_*.csv_shuffled.csv`, `sample_D22_*.json`)

## Anonymization Pipeline (example: B22_3)
```
python anonymization/ano.py in/B22_3.csv out/C22_3.csv
python anonymization/randomshuffle_rows.py out/C22_3.csv out/C22_3_shuffled.csv
python anonymization/gen_Di.py in/B22_3.csv out/C22_3_shuffled.csv out/sample_D22_3.json
```

### Accuracy check for C22_*
```
python anonymization/MLacc_files.py
```
Output: `out/MLacc_files.txt`

Note: The accuracy here reflects inference errors on `stroke_flag` only.

## Attack Setup
1) Create directory: `out\PWSCUP2025_Pre_Data_for_Attack`
2) Unzip all `PWSCUP2025_Pre_Data_for_Attack_**` into `out\PWSCUP2025_Pre_Data_for_Attack`

Attack types:
- attackCi: distance-based attack on Ai↔Ci common columns
- attackDi: combination of Prediction attack and Confidence attack

Example (distance + prediction + confidence):
```
python attack/attack_example.py -o out/Fij_01.csv \
  out\PWSCUP2025_Pre_Data_for_Attack_01-05\A01.csv \
  out\PWSCUP2025_Pre_Data_for_Attack_01-05\C01.csv \
  out\PWSCUP2025_Pre_Data_for_Attack_01-05\D01.json
```
Note: `Fij_01.csv` has 100,000 records. The sample produced 66,575 positives (>10,000 limit), likely with many Type II errors (false negatives) due to thresholding.

## Ideas / Proposals
- Proposal 0 (easy/efficient): limit positives to 10,000 using original score
- Proposal 1 (Ci, moderate): limit to 10,000 via Hungarian algorithm in attackCi
- Proposal 2 (Di, easy): raise confidence threshold for AttackDi
- Proposal 3 (Ci+Di, moderate): add noise to Ci/Di answers and weight by noise
- Proposal 4 (Di, hard): search ML model patterns by training variants and compare to target
- Proposal 5 (Ci, moderate/efficient): mutual nearest neighbors (Ci→Ai and Ai→Ci)
- Proposal 6 (Ci, moderate/efficient): extend 1-NN to k-NN

## new_attackDi_Ci (rank Di candidates by Ci distance and |pred - y|)
Outputs top-N rows (default 1). Quick examples:
```
# Union of Pred and Conf (each top-10,000); Ci k=5; emit top 10,000
python attack\new_attackDi_Ci.py \
  out\PWSCUP2025_Pre_Data_for_Attack\A22.csv \
  out\PWSCUP2025_Pre_Data_for_Attack\C22_fix.csv \
  out\PWSCUP2025_Pre_Data_for_Attack\D22.json \
  --pred-topk 10000 --conf-topk 10000 --mode union -k 5 --w-conf 1.0 --topn 10000 \
  -o out\Fij_new_22.csv --out-rank out\Fij_new_22_rank.csv
```

Heuristic for k-NN matching (Ci): take up to k nearest neighbors; match the closest pair first, then continue greedily among remaining unmatched items. Greedy tie-breaking by smaller ID is acceptable since we infer membership, not exact pairings.

## attack_allCi_allDi_hungarian (sum of Ci Hungarian distance and Di |pred - y|)
Ranks all Ai rows by: Hungarian matched distance (Ci→Ai) + |pred - y| from Di. Selects top 10,000 without Di candidate filtering.
```
python attack\attack_allCi_allDi_hungarian.py \
  out\PWSCUP2025_Pre_Data_for_Attack\A22.csv \
  out\PWSCUP2025_Pre_Data_for_Attack\C22_fix.csv \
  out\PWSCUP2025_Pre_Data_for_Attack\D22.json \
  --hung-mode knn -k 300 --topn 10000 \
  --w-dist 1.0 --w-conf 1.0 --auto-wdist \
  -o out\Fij_all_hungarian_22.csv \
  --out-rank out\Fij_all_hungarian_22_rank.csv \
  --out-map out\C22_matchmap_all_hungarian.csv
```
Notes:
- Ci distance uses unified Manhattan distance on common columns (numeric scaled, categorical one-hot) and Hungarian min-sum matching. Unmatched Ai get a large fill cost.
- Di distance is |pred - y| from Conf_Attack.
- Combined cost per pair = `w_dist * Ci_distance + w_conf * |pred - y|` (smaller is better).
- `--auto-wdist` scales `w_dist` by 1/(N+2*C) using counts of shared numeric (N) and categorical (C) columns.

## Attack Variants
Choose from the following implementations.

### Ci attack (original / extended / greedy)
```
python attack\attack_Ci.py out\PWSCUP2025_Pre_Data_for_Attack\A22.csv out\PWSCUP2025_Pre_Data_for_Attack\C22_fix.csv -o out\C22_inferred.csv

python attack\attack_Ci_ex.py out\PWSCUP2025_Pre_Data_for_Attack\A22.csv out\PWSCUP2025_Pre_Data_for_Attack\C22_fix.csv -o out\C22_inferred_ex.csv -k 1

python attack\attack_Ci_ex_greedy.py out\PWSCUP2025_Pre_Data_for_Attack\C22_fix.csv out\PWSCUP2025_Pre_Data_for_Attack\A22.csv -m nn -k 5 -o out\C22_inferred_ex_greedy_k5_nn.csv

python attack\attack_Ci_ex_greedy.py out\PWSCUP2025_Pre_Data_for_Attack\C22_fix.csv out\PWSCUP2025_Pre_Data_for_Attack\A22.csv -m greedy -k 20 -o out\C22_inferred_ex_greedy_k20_greedy.csv --out-map out\C22_matchmap_k20.csv
```

### Di attack (original / extended)
```
python attack\attack_Di.py out\PWSCUP2025_Pre_Data_for_Attack\D22.json out\PWSCUP2025_Pre_Data_for_Attack\A22.csv

python attack\attack_Di_ex.py \
  out\PWSCUP2025_Pre_Data_for_Attack\D22.json \
  out\PWSCUP2025_Pre_Data_for_Attack\A22.csv \
  [--pred-threshold 0.5] [--pred-topk 10000] [--pred-pos-ratio 0.10] \
  [--conf-threshold 0.1] [--conf-topk 10000] [--conf-pos-ratio 0.10] \
  --out-pred out/inferred_membership1_22_ex.csv \
  --out-conf out/inferred_membership2_22_ex.csv
```
